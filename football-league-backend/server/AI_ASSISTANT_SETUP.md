# AI足球小助手配置指南

## 功能说明

AI足球小助手是基于阿里云通义千问（DashScope）API实现的智能对话助手，专注于足球赛事、球队球员、比赛规则、战术分析等相关知识解答。

## 配置步骤

### 1. 获取阿里云DashScope API Key

1. 访问阿里云DashScope官网：https://dashscope.aliyun.com/
2. 登录/注册阿里云账号
3. 进入控制台，创建应用
4. 获取API Key（格式：`sk-xxxxxxxxxxxxxxxx`）

### 2. 配置环境变量

在 `server/.env` 文件中添加以下配置：

```env
# 阿里云通义千问API Key（AI足球小助手）
DASHSCOPE_API_KEY=sk-your-actual-api-key-here
```

**重要提示**：
- 将 `sk-your-actual-api-key-here` 替换为你实际获取的API Key
- 不要将真实的API Key提交到Git仓库
- 建议在 `.gitignore` 中添加 `.env` 文件

### 3. 重启后端服务

配置完成后，重启NestJS后端服务：

```bash
cd server
npm run start:dev
```

## API接口

### POST /ai/chat

**请求体**：
```json
{
  "question": "什么是越位规则？"
}
```

**成功响应**：
```json
{
  "answer": "越位是足球比赛中的一项重要规则..."
}
```

**错误响应**：
```json
{
  "answer": "抱歉，我暂时无法回答这个问题。请检查AI服务配置或稍后重试。",
  "error": "AI服务配置异常，缺少API Key"
}
```

## 前端使用

前端已集成 `FootballAiChat` 组件，位于右下角悬浮按钮。

**组件位置**：`front-end/src/components/FootballAiChat.tsx`

**使用方式**：
1. 点击右下角绿色足球图标
2. 在对话框中输入问题
3. 按回车或点击"发送"按钮
4. AI助手会自动回复

## 常见问题

### Q1: 提示"AI服务配置异常，缺少API Key"
**A**: 检查 `.env` 文件中是否正确配置了 `DASHSCOPE_API_KEY`，并重启后端服务。

### Q2: 提示"网络异常，无法连接到AI服务"
**A**: 
1. 检查后端服务是否正常运行（默认端口5002）
2. 检查前端环境变量 `NEXT_PUBLIC_API_URL` 是否正确
3. 检查网络连接是否正常

### Q3: AI回答速度慢
**A**: 
1. 检查网络连接速度
2. 阿里云API可能有区域限制，建议使用国内网络
3. 可以调整 `ai.service.ts` 中的 `max_tokens` 参数减少响应内容长度

### Q4: AI回答不准确
**A**: 
1. 可以修改 `ai.service.ts` 中的 `SYSTEM_PROMPT` 优化提示词
2. 调整 `temperature` 参数（0.7为默认值，降低可提高准确性但减少创造性）
3. 调整 `top_p` 参数（0.8为默认值）

## 成本说明

阿里云通义千问API采用按量计费：
- 免费额度：新用户有一定免费调用额度
- 计费方式：按Token数量计费
- 建议：开发测试阶段使用免费额度，生产环境需要充值

## 安全建议

1. **不要泄露API Key**：API Key具有调用权限，泄露可能导致费用损失
2. **设置调用限制**：在阿里云控制台设置每日调用上限
3. **监控使用情况**：定期检查API调用量和费用
4. **环境隔离**：开发/测试/生产环境使用不同的API Key
